# 🌾 SokoGuard AI

> An AI-powered market intelligence assistant that helps Kenyan farmers and traders avoid being underpaid by giving fair price estimates, negotiation advice, and real-time market insights.

---

## 🚀 Live Demo
👉 https://ai.studio/apps/4bf50897-1aff-47b7-9f5b-8b087847c943

---

## 🧠 Problem Statement

In many Kenyan markets, small-scale farmers and traders often sell their produce without knowing the true market value. This leads to frequent underpricing and exploitation by middlemen.

---

## 💡 Solution

**SokoGuard AI** solves this by acting as a personal AI market expert that:

- Estimates fair market prices in KES
- Detects risk of being underpaid
- Gives negotiation advice in simple English + Swahili/Sheng
- Provides localized market insights (e.g. Gikomba, Wakulima, Kongowea)

---

## ⚙️ Features

- 🤖 AI-powered price analysis using Gemini
- 📍 Location-aware market insights
- ⚠️ Risk level detection (Low / Medium / High)
- 💬 Smart negotiation advice
- 📊 Structured AI responses for clarity
- 📱 Simple, mobile-friendly interface

---

## 🏗️ Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js + Express  
- AI: Google Gemini API  
- Deployment: Google Cloud Run / AI Studio
